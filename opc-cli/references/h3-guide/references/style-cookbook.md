# H3 Style Cookbook

## 目录

- 品牌大片与电影预告
- 时尚 Campaign
- MG、动画片头与动态海报
- Dark-pop、Cyber-grunge 与杂志拼贴
- 实拍与手绘发光动画
- 剧情与短剧
- 产品与电商
- 游戏、网页与 UI 演示
- 动画、二次元与游戏 CG
- 材质转场与视觉实验

每种风格都用“视觉语法 + 时间动作 + 声音 + 参考职责 + 禁止项”表达，不只堆风格名。

## 品牌大片与电影预告

### 望远镜窥视式品牌片

- 视觉：固定双圆镜片遮罩、黑色羽化暗角、35mm 颗粒、克制色彩、红色文字点缀。
- 动作：手持虚焦开场，快速推进并 rack focus；切图时使用甩动、运动模糊、光学拖影和曝光闪烁，在最模糊处换帧。
- 约束：遮罩位置、大小和边缘虚化全程绝对一致，只有遮罩内部运动。
- 文字：随对焦从低透明度变清晰，轻微滑入或字距呼吸，切换前被模糊带走；禁止旋转、弹跳和大幅飞入。
- 参考：四张图分别承担连续关键帧，不允许新增建筑、人物、车辆或 Logo。

### 太空歌剧/科幻悬疑预告

- 视觉：超广角奇观、人物作为小比例剪影、高反差、深空暗部、潮湿反光、暗红或铁锈红标题。
- 剪辑：快速硬切、短黑场、舰桥震动、强光爆闪、跃迁冲击。
- 文字：极窄或宽字距大标题，从暗部渐入、被星光扫亮、字距展开、轻微边缘辉光。
- 声音：深低频脉冲、金属震动、紧张弦乐或合成器；标题清晰时给轻 hit。
- 避免：宏大但拖慢、廉价纯白标题、连续柔和溶解。

## 时尚 Campaign

- 把场景、人物三视图、产品三视图和 ending Logo 分别绑定。
- 用简单行为承载产品：回到车尾、打开后备箱、拿起包、短暂对视、离开。产品自然进入行为，而不是漂浮展示。
- 视觉可选：冷感荒漠公路胶片；或夜晚火场、黑烟、橙红反射、VHS 故障、扫描线、色差和闪白。
- 剪辑要灵动但克制，像 fashion campaign，不像剧情片或电商口播。
- 保持服装、脸、产品几何和材质；不要让 moodboard 覆盖身份图。

## MG、动画片头与动态海报

### 复古日系犯罪动画片头

- 视觉：硬边剪影、漫画拼贴、非对称分屏、几何色块、黑底线框、英文署名和少量片假名装饰。
- 动效：线框先画出，分屏边界切入，色块/画格逐块贴入；人物和道具随鼓点通过滑入、弹出、遮罩揭示出现。
- 转场：黑胶圆形遮罩、车门竖切、长影擦屏、红线切割、巨大字母遮罩、分屏重组和色块硬切。
- 声音：60% 悬疑、40% 爵士；低音持续音、拨奏、冷感脉冲、低音鼓、稀疏鼓刷、walking bass、低音萨克斯和短铜管。
- 文字规则：姓名和职位各出现一次，禁止错拼、重复职位、乱码和中文增生。

### 动态海报

- 把原图版式、白框、内框、红白黑配色和主体比例设为不变量。
- 只动画化层级：标题、信息栏、主体微旋转、光效和少量视差。
- 文字出现要配轻巧音效；不要重排版、替换字体或让主体走出画框。

## Dark-pop、Cyber-grunge 与杂志拼贴

- 视觉：90 年代末至 00 年代初独立杂志、复印纸、地下音乐海报和 zine 拼贴。
- 材质：粗颗粒、半色调网点、印刷毛边、扫描错位、胶片抖动、色差。
- 剪辑：快节奏硬切，不用淡入淡出或柔和转场。
- 画面：高反差写实时装，控制黑位和红色点缀，避免廉价霓虹赛博朋克。
- 参考图主要负责排版与材质，角色图负责身份和服装。

## 实拍与手绘发光动画

- 真实层：手机单手拍摄、轻微手抖、对焦犹豫、逆光曝光波动、暗部噪点和生活化杂物。
- 动画层：柔和发光线条、生物或涂鸦遵循真实物体遮挡和空间透视。
- 情绪递进：小火花 → 明亮光芒 → 关键关系动作时改变颜色或笔触。
- 声音：真实环境声、脚步、呼吸、器物轻碰，加柔和电子音和小叫声。
- 避免：整理得像广告、巨眼獠牙、扑袭、跳吓、突然黑屏。

## 剧情与短剧

### 武侠悬疑

- 场景：夜竹林、薄雾、细雪、冷蓝/墨绿/灰黑低饱和。
- 构图：前景虚化竹叶形成窥视层次，冷白侧前光，背景逆光，浅景深。
- 剪辑：人物近景/特写正反打，节奏克制但紧张。
- 表演：通过目光、停顿、呼吸和细微手部动作建立秘密情报交接感。
- 避免现代元素、平台水印、过度磨皮、动画感和喜剧表演。

### 竖屏家庭冲突

- 明确人物关系、台词目的和情绪梯度，不只写“争吵”。
- 9:16 中近景和频繁正反打，暖色生活空间、浅景深、真实短剧表演。
- 分别指定每个人的情绪：愤怒/委屈/急切，与尖锐/强势/步步紧逼。
- 不要舞台腔、夸张肢体和无关字幕。

### 海外暗黑爱情短剧

- 以 15 秒钩子为目标：误入禁区、唤醒危险角色、发现宿命气息、压迫与反抗。
- 9:16 以脸、眼神、距离和控制关系为中心，暗黑浪漫但不血腥、不万圣节。
- 人物图负责固定男女主，场景图负责古堡和色调。

## 产品与电商

### 时尚配饰广告

- 分离场景/造型图、人物外貌图和产品设计图。
- 强调产品几何：包覆式弧面、锐利猫眼/护目镜轮廓、镜面反射、镜腿结构。
- 白棚、高定、冷峻、国际秀场气质；人物动作服务产品可见性。

### 功能可视化

- 用“外观展示 → 材料微观 → 结构工程动画 → 调节演示 → 使用场景 → 支撑示意 → 空间陈列 → 品牌落点”的顺序。
- 每个功能给可视化机制：空气流动、腰部曲线、部件调节、骨骼支撑，而不是只念卖点。
- 产品图负责几何，说明图负责功能，禁止零件数量、结构和材质漂移。

## 游戏、网页与 UI 演示

- UI 动画用秒级状态机写：菜单 → 点击 → 部件面板 → 机械重组 → 确认 → loading → 世界加载。
- 同时描述摄像机位置、角色状态、按钮状态和环境变化。
- 网页演示明确滚动方向、标题/信息栏进入方向、hover 放大/反色和主体微动。
- 文字越多越容易出错；锁定最重要字符串，其他信息用图形占位并准备后期替换。
- 避免把 UI 当贴纸漂浮在场景上，要求透视、层级、遮挡和点击反馈一致。

## 动画、二次元与游戏 CG

- 黏土动画：强调手工材质、形变、英雄式慢动作和大动态掠过，不要变成光滑 3D 塑料。
- 国风 3D/仙侠：人物图固定发冠、发带、服装层级、腰封和流苏；分镜图负责镜头顺序。远景只给背影/侧背，露脸用近景特写。
- 乙游 PV：角色三视图固定脸、发型、体型、服装和 CG 材质；把暧昧关系动作拆成具体近景。
- FPS：第一人称眼平手持、枪械后坐力、准星扫描、推进节奏、冷色自然光和烟雾火光；保持游戏 HUD 与相机逻辑。
- 视觉小说转场：首尾帧固定 UI 状态，用遮罩、按钮反馈、对话框和表情变化过渡，不做 PPT 式切换。

## 材质转场与视觉实验

- 找首尾素材的共享视觉属性：颗粒、曲线、方向、明暗或液体运动。
- 先微距推进，让纹理覆盖全屏并遮掉其他物体；在相似度最高的瞬间完成材质转换，再拉出新场景。
- 例：咖啡粉/奶泡/涟漪 → 沙粒/沙脊/风蚀纹理。
- 明确一镜到底、无黑屏、无硬切、无画面开裂、无拼接感。
