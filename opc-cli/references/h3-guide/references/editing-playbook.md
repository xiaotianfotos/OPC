# H3 Editing Playbook

## 目录

- 总原则
- 角色与物体替换
- 增加或删除对象
- 背景、光影与特效
- 动作与运镜迁移
- 多项精确修改
- 台词、音色与表演
- 首尾帧与材质变换

## 总原则

编辑任务默认选择 `h3-r2v`。Prompt 的第一段先把 `<Video 1>` 定义为严格的机位、构图、时序、动作路径、遮挡、环境和声音来源；第二段只列允许变化的内容；最后再次声明“其余不变”。

把变化拆成可检查的清单，避免“整体优化”“更高级”这种会授权模型重拍整条视频的描述。

## 角色与物体替换

### 纯文字替换

适合目标类别差异明显、无需固定某个个体时，例如“把猫换成纯蓝灰英短”“把猫换成狗”。写清：

- 目标物种/品种、体型、脸型、颜色、毛长、纹理和典型特征。
- 原主体最容易残留的相反特征，明确禁止保留。
- 保持原动作路径、接触点、重力、遮挡和镜头。

### 参考图身份替换

适合指定人物、宠物、服装或产品：

- 一张全身/三视图负责比例和服装。
- 一张脸部或细节图负责五官、标记和材质。
- Prompt 明确图片中的背景、鞋子、家具等无关元素不得进入视频。

视频条件可能强于身份图，常出现“脸和花纹变了，但原主体轮廓仍在”。先强化目标与原属性排除；若两次迭代仍收敛，改用差异更大的文字替换、分镜重生成或遮罩合成。

## 增加或删除对象

- 指定画面区域、进入时机、数量、服装/材质和动作同步对象。
- 新增人物时说明与哪位旁人动作一致，以及镜头内的站位和遮挡关系。
- 删除对象时说明删除后的背景如何补全，避免留影、残肢、漂浮或重复。
- 不要只写“加一个人”；写“画面左侧增加一名穿同款团队制服的人，与右侧两人同速前进并保持相同步态”。

## 背景、光影与特效

### 背景替换

- 视频负责人物、动作、机位和前景；图片或第二视频只负责新背景风格。
- 写清地平线、地面接触、反射、阴影、透射光和人物边缘光如何匹配。
- 绿幕编辑明确去除绿边、溢色和原背景残留。

### 光影替换

- 固定场景几何和动作，只改变时间、主光方向、色温、天空、窗口亮度和阴影。
- “改成夜晚”应展开为曝光、实用光源、冷暖关系、反射和噪点，而不是简单压暗。

### 局部风格化

- 指定哪些对象风格化、哪些保持真实。例如只把树木和轿车变成体素积木，建筑、行人和环境保持实拍。
- 风格化对象仍要保留运动轨迹、真实阴影、接触和透射关系。

## 动作与运镜迁移

- 图片负责人物身份，视频只负责动作、表情节奏或运镜。
- 把复杂动作按先后复述，特别是多人交换位置、翻滚、堆叠或接触。
- 运镜参考要命名具体机制，如 Hitchcock dolly zoom，并说明目标视频的人物/表演来源。
- 动作和身份发生冲突时，优先固定接触关系与身体重心，再追求服装细节。

## 多项精确修改

逐项编号，并在结尾列不变量。示例结构：

```text
1. 报纸替换成绿色封皮书。
2. 椅子替换成红色沙发。
3. 移除墨镜，露出清晰面部。
4. 移除汽车燃烧效果，车辆保持正常。
5. 照片替换成黑色小本子。
6. 画面左侧增加一棵树。

保持人物身份、表演、镜头、时序、背景其余区域和声音不变。
```

超过 4–6 个互相独立的改动时，先判断是否需要拆成两轮；一次生成中“保留所有精细不变量”与“大范围改动”常互相竞争。

## 台词、音色与表演

- 明确原台词、目标台词、说话人、语言、情绪和呼吸状态。
- 要求口型与目标音频同步，并允许只对相关表情、停顿和眼神做最小调整。
- 视频自带音轨会影响 `<Audio N>` 编号；命令提交前 dry-run 核对。
- 如果目标是克隆音色，写“角色说出精确台词，音色参考 `<Audio N>`”，同时保持场景环境声。
- 不要把原视频音频无条件后期覆盖回生成视频；H3 可能重新安排动作时序，先检查口型和事件时间。

## 首尾帧与材质变换

- 首帧严格定义起始构图，尾帧严格定义结束状态。
- 找两帧之间的共享形状或纹理，把它作为遮挡/转化桥梁。
- 明确镜头始终如何运动，以及转化发生在画面被纹理填满的哪一瞬间。
- 禁止黑屏、硬切、画面开裂和突然更换焦段。
