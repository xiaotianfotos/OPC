## 首轮策略

- 使用低成本安全测试：864x480、5 秒、20 steps、固定 seed。
- 先验证最危险约束：身份、产品几何、文字、动作接触或编辑不变量。
- 一个测试只改变一个主要变量，记录 seed、Prompt、媒体顺序和输出路径。
- 参考媒体多时，先做最小可行组合；确认后再增加风格/音频参考。

## 视觉质检

不要只看首帧。至少执行：

1. 按等间隔抽取 6 帧组成 contact sheet。
2. 在身份、产品、文字或手部最关键的 2–4 个时刻抽高清帧。
3. 把原视频、目标参考和生成帧并排比较。
4. 检查全片是否出现身份漂移、重复主体、闪烁、材质突变、错误遮挡或背景重画。
5. 对编辑任务逐项核对“改了什么”和“本应不变的内容”。

## 声音与时序质检

- 用 `ffprobe` 检查是否有音轨、采样率、声道数、帧率和实际时长。
- 完整解码音视频，排除损坏帧和音轨错误。
- 检查对白/张嘴、撞击/动作、转场/音乐 hit 的同步。
- 参考视频时长与 H3 帧网格不一致时，动作可能被重新编排。不要只裁尾或直接换回原声；先定位相同事件，再决定变速、剪辑或保留 H3 音轨。

## 失败分类

| 现象 | 首选修复 |
|---|---|
| 身份像，但体型/毛长仍像原视频 | 明确排除原属性；增加全身/三视图；必要时改为更强文字类别替换 |
| 动作准确，场景/身份被参考视频带偏 | 把视频职责限定为动作/运镜；重复列出场景和身份不变量 |
| 多张图融合成混合角色 | 给每张图唯一职责；删掉冗余图；明确不得融合 |
| 产品几何漂移 | 减少动作幅度；增加多视角产品图；固定 Logo、边缘和零件数 |
| 文字乱码或重复 | 缩短文案；规定只出现一次；把精确长文字移到后期 |
| 编辑导致整场重拍 | 把原视频不变量放到 Prompt 开头和结尾；删掉宽泛审美词 |
| 动作/口型与原声错位 | 保留 H3 生成音轨，或基于事件点重定时；不要直接 remux 原声 |
| 过度精致、失去手机实拍感 | 加入手抖、对焦犹豫、曝光波动、暗部噪点和生活化杂物 |
| 结果两次几乎相同且缺陷一致 | 认定条件冲突/模型边界，拆镜或转后期，不继续只改形容词 |

## 迭代决策

按下列顺序只改一项：

1. 修正媒体序号和职责冲突。
2. 强化不变量与目标/原属性对照。
3. 删除不必要参考素材。
4. 调整构图或参考裁切，让目标主体占画面更大。
5. 换 seed 验证是随机性还是结构性失败。
6. 拆成两镜或两阶段任务。
7. 对文字、Logo、局部遮罩和帧级精确编辑转后期合成。

经验边界：视频参考对动作、构图和主体轮廓的约束很强；参考图更容易改变脸、花纹和材质，未必彻底改变轮廓。纯文字指定差异显著的类别有时比“相似个体照片替换”更容易完成明显的外观替换。

## 交付检查

- 最终文件位于用户指定目录，命名能区分 Prompt/seed/版本。
- H.264/yuv420p 等兼容规格、分辨率、24 fps、音轨和时长符合预期。
- `ffmpeg -v error -i final.mp4 -f null -` 无错误。
- 保留最终 Prompt、媒体映射和 contact sheet。
- 向用户说明成功点、仍可见的边界、是否使用 H3 原生/重建音轨。
